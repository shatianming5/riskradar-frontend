# RiskRadar Frontend

RiskRadar is a college-student personal finance risk-control Agent demo. It helps users pause before paying, borrowing, sharing sensitive credentials, or making investment decisions by showing a risk score, evidence, calm-check questions, next actions, and a safe reply template.

## Features

- Three-panel risk-control workspace
- One-click demo cases for payments, refunds, social investment hype, borrowed-money investing, and low-risk checks
- Local TypeScript scoring engine based on the project rules
- Agent Teams trace: detective, risk-control, red-team, and coach agents
- Responsive layout for desktop and mobile

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:5173/`.

## Build

```bash
npm run build
```

The production build is written to `dist/`.
