# RiskRadar 大学生个人金融风险冷静器

## 主题

金融 / 风控

## 项目简介

RiskRadar 是一个面向大学生和年轻用户的个人金融风险控制 Agent。它覆盖转账、兼职押金、二手交易、校园缴费、借款、退款、账户安全、基金股票黄金等理财决策与社群荐投等高频场景，在用户做出付款、借贷、提交敏感资料或下单投资前进行风险识别、风险评分、证据解释和行动建议生成。系统通过“多 Agent 推理 + 规则评分 + 风险案例库”的方式，将复杂的金融风控能力转化为用户可理解的“风险等级、三问冷静卡和安全回复模板”。

## Idea 描述

许多风险并不是发生在损失之后，而是在个人金融决策前的几分钟就已经暴露出明显信号，例如前置收费、脱离平台、个人账户冒充官方、制造紧迫感、要求验证码或屏幕共享，也包括“不了解产品投什么、不知道费用和赎回规则、借钱理财、重仓跟风上车”等理财风险。RiskRadar 希望抓住这个关键窗口，让 AI 在用户冲动付款、借贷或下单前介入，用 30 秒完成风险冷静、证据解释和行为建议。

项目口号：

不是替你下单，而是在你做金融决策前，让 AI 帮你冷静 30 秒。

## 用户交互方式

用户可以通过以下方式与系统交互：

1. 粘贴聊天记录、短信、收款说明、网页文案、理财推荐话术等文本。
2. 输入结构化信息，例如金额、收款方、交易用途、付款渠道、是否要求立即付款。
3. 在理财场景补充产品名称、是否知道底层投向、是否了解费率和赎回规则、资金是否来自闲钱或借款。
4. 上传截图识别后的文本，或在 Demo 中以 OCR 后文字模拟输入。
5. 补充用户画像信息，例如是否为学生、是否第一次交易、是否熟人推荐、是否在平台内交易。

系统在接收输入后，依次完成场景识别、关键信息抽取、规则评分、证据解释、三问冷静卡生成和下一步行动建议输出。如果信息不足，系统最多追问 3 个关键问题；在理财场景优先追问产品是什么、费用和赎回规则是否清楚、资金是否来自闲钱，以降低使用门槛与决策负担。

## 核心输出

每次输出固定包含以下模块：

1. 风险等级：低风险 / 中风险 / 高风险 / 极高风险
2. 风险分数：0-100
3. 场景判断：识别为兼职押金、二手交易、熟人借钱、校园缴费等主场景
4. 判断依据：3-5 条可解释理由
5. 可疑证据 / 信息缺口：引用用户输入中的关键词、原句或未补足的关键信息
6. 三问冷静卡：用户在付款、借贷或投资前必须完成的 3 个核验问题
7. 下一步行动：暂停付款、转回官方渠道、补足产品信息、保留证据、联系平台或老师等
8. 可直接复制的安全回复模板

## 技术选型

### 1. LLM 能力层

用于场景识别、信息抽取、解释生成、追问设计与安全回复模板生成。

### 2. 规则引擎层

根据前置收费、脱离平台、主体不一致、紧迫感、验证码请求、屏幕共享、不了解产品、借钱理财、重仓、群体荐投等信号进行打分，保证结果稳定、可解释、便于现场展示。

### 3. 风险知识库 / RAG 层

存储风险类型、风险话术、核验建议与案例样本，为系统提供案例对照和说明支撑。

### 4. 多 Agent 协作层

- 侦探 Agent：提取交易要素和风险线索
- 风控 Agent：根据规则与案例库计算风险分数
- 红队 Agent：推演对方后续可能的诱导路径
- 教练 Agent：生成用户真正可执行的建议与安全回复

### 5. ArkClaw Skill 层

将风控流程、规则、案例与输出格式封装成可跑通的 Skill 包，保证评审可复现、可查看、可演示。

### 6. Coze Workflow 层

负责构建体验链接与展示页面，将风险评分、证据卡片、三问冷静卡和建议行动以更直观的交互形式呈现给评委与用户。

## 技术流程

用户输入后，系统首先完成个人金融场景识别，并抽取金额、收款方、关系、渠道、紧急程度、是否脱离平台、是否前置收费、是否要求验证码或屏幕共享等核心字段；在理财场景进一步抽取产品类型、底层投向理解程度、费率和赎回规则掌握情况、资金来源及仓位倾向。随后规则引擎对高危与安全信号进行加减分，生成 0-100 的风险分数与等级。最后由 LLM 结合知识库生成证据解释、三问冷静卡、下一步行动和安全回复模板。

## 典型场景

1. 兼职押金：要求先交资料费、保证金、认证费
2. 二手交易：要求脱离平台、加微信、先付定金
3. 熟人借钱：身份未核验、紧急转账、第三方收款
4. 校园缴费：识别官方平台和主体一致的低风险场景
5. 网购退款：冒充客服、索要验证码、诱导远程操作
6. 理财决策：不了解产品、不了解费用、不了解赎回规则
7. 社群荐投：高收益承诺、拉群带单、限时催促、跟风下单
8. 借钱理财：使用花呗、借呗、校园分期或借来的钱投资

## 用户交互展示设计

Coze 展示页建议采用三栏结构：

- 左侧：用户输入的聊天记录或交易描述
- 中间：风险分数仪表盘、风险等级、场景判断
- 右侧：三问冷静卡、下一步行动、安全回复模板

这样的布局能让评委在数秒内看清输入、判断与行动之间的逻辑链路，突出“用户交互”和“演示效果”。

## 创新点

1. 不是事后止损，而是把风控前移到个人金融决策前 30 秒
2. 不是只给一句“有风险”，而是给出可解释证据、信息缺口和可执行建议
3. 不是单一大模型输出，而是“多 Agent 推理 + 规则打分 + 风险案例库”混合架构
4. 不要求财务报表和复杂图表，也能处理大学生常见的理财信息不足场景
5. 能同时覆盖高风险场景与正常缴费、低风险理财场景，避免一刀切误报

## 商业与社会价值

对个人用户，RiskRadar 可以减少冲动付款、盲目借贷和不了解产品就下单的风险；对校园、银行、券商、支付机构和平台，RiskRadar 可以作为前置风险教育和轻量风控解释层；对比赛场景，它具备明确的社会价值、良好的演示效果和可复用的技术框架。

## 与赛题的匹配性

本项目严格归类于“金融 / 风控”主题，核心目标是大学生个人金融场景中的前置风险控制，而不是支付工具、授信模型或纯反欺诈识别系统。系统通过可解释风控提醒帮助用户在风险尚未发生前暂停付款、暂停下单、完成核验、补足产品信息或保留证据，主题边界清晰，便于在初赛与复赛评审中准确传达项目定位。

## 总结

RiskRadar 的价值不是替代银行或券商风控，而是把专业风控前移到用户决策的一刻。它将复杂的风控能力转化为大学生和年轻用户听得懂、用得上的提醒系统，兼具主题匹配度、创新性、交互体验与社会价值。
