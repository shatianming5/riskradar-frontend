# 风险场景分类

选择一个最主要的场景标签，避免同时给出多个主标签。

## 场景清单

| 场景 | 典型关键词 | 主要风险点 |
| --- | --- | --- |
| `转账付款` | 转账、付款码、打钱、垫付 | 冲动支付、收款主体不明 |
| `二手交易` | 闲置、定金、卖家、加微信、平台手续费 | 脱离平台、先付定金 |
| `兼职押金` | 兼职、入职、培训费、资料费、保证金 | 前置收费、高收益诱导 |
| `网购退款` | 客服、退款、退赔、账户异常 | 冒充客服、验证码、远程控制 |
| `校园缴费` | 学校、报名费、活动费、统一支付平台 | 真假通知与收款主体核验 |
| `借款/校园贷` | 借钱、垫付、分期、征信、放款 | 假借贷、暴力催促、资料套取 |
| `理财决策` | 基金、股票、黄金、ETF、宽基、定投、理财、费率、赎回、锁定期 | 不了解产品、不了解费用和流动性、短期用钱错配 |
| `社群荐投` | 群老师、带单、喊单、博主推荐、内幕消息、开户链接、直播间 | 高收益承诺、跟风上车、信息源不可靠、非官方链接 |
| `熟人借钱` | 同学、朋友、手机坏了、先帮我转 | 身份冒充、第三方收款 |
| `账号租借` | 租号、代实名、刷流水、账号共享 | 账户风险与连带责任 |
| `验证码/屏幕共享` | 验证码、共享屏幕、远程、下载软件 | 账户接管、资金被盗 |

## 选择规则

- 先看用户准备做的动作，再看对方话术。
- 若同时涉及多个标签，优先选择最接近付款决策的一项。
- 若用户已经准备购买基金、股票、黄金或理财产品，但主要问题是“看不懂、不了解、跟风”，优先选择 `理财决策`。
- 若用户是因为群聊、老师、主播、同学、社交媒体推荐而准备下单，优先选择 `社群荐投`。
- 若用户说的是“下个月房租/学费/生活费先买一下理财”，即使没有明显诈骗，也优先放在 `理财决策`，因为这是典型个人金融风控问题。
- 若用户已经完成付款，仍以原付款场景命名，再补充事后止损建议。

## 大学生投资理财场景提示

- 不要把所有基金、股票、黄金场景都默认成高风险或诈骗。
- 真正需要识别的是：
  - 是否看不懂产品却准备下单
  - 是否只凭群聊、博主、老师带单
  - 是否使用借款、生活费、房租、学费
  - 是否不清楚费率、锁定期、到账时间
- 如果用户走官方持牌渠道、只用闲钱、小额分散、明确知道产品和波动，可以给出低风险或中低风险判断。
