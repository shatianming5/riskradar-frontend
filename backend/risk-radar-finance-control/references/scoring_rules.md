# 风控评分规则

## 高危加分信号

| key | 触发条件 | 分值 | 解释 |
| --- | --- | --- | --- |
| `upfront_fee` | 要求先交保证金、押金、认证费、解冻费、手续费、定金 | +25 | 典型前置付款风险 |
| `off_platform` | 要求加私聊、跳出平台、私下转账、线下交易 | +20 | 失去平台担保与申诉链路 |
| `personal_receiver_claims_official` | 个人账户收款但声称官方、学校、企业、平台 | +20 | 主体声明与收款方式不一致 |
| `asks_for_sensitive_credentials` | 要求验证码、支付密码、银行卡完整信息、身份证照片 | +40 | 涉及高敏感凭证 |
| `asks_for_screen_share` | 要求屏幕共享、远程控制、下载不明 App 协助操作 | +40 | 常见接管账户信号 |
| `high_return` | 承诺高返利、稳赚、轻松赚钱、刷单回本 | +20 | 高收益诱导 |
| `urgency_pressure` | 强调马上付款、名额有限、超时失效、不转后果严重 | +15 | 制造紧迫感压缩核验时间 |
| `entity_mismatch` | 沟通主体、交易主体、收款主体不一致 | +20 | 交易链条异常 |
| `cannot_verify` | 无法通过官方渠道核验身份、订单、通知或合同 | +15 | 缺少独立核验路径 |
| `student_or_first_time` | 用户是学生、新手、第一次交易或缺乏经验 | +10 | 更容易被行为诱导 |
| `emotion_manipulation` | 要求保密、诉诸同情、威胁、制造内疚或恐吓 | +15 | 使用情绪操控推动支付 |
| `identity_impersonation` | 冒充熟人、客服、老师、官方人员或机构 | +25 | 身份伪装类高危信号 |
| `third_party_receiver` | 要求代付、转给朋友或第三方收款人 | +15 | 转账对象异常 |
| `unknown_product` | 不清楚产品是什么、投什么、风险等级如何 | +15 | 理财产品认知不足 |
| `social_hype_only` | 主要根据群友、博主、主播、同学或老师带单决定 | +15 | 信息源单一且容易跟风 |
| `leverage_or_borrowed_money` | 借钱、花呗、借呗、校园分期、贷款去投资 | +25 | 资金来源与风险承受力不匹配 |
| `cashflow_mismatch` | 把房租、学费、生活费或短期必用资金放进波动或锁定期产品 | +20 | 现金流与产品期限不匹配 |
| `all_in_or_high_concentration` | 满仓、梭哈、重仓、把大部分生活费压进去 | +15 | 集中度过高 |
| `unknown_fee_or_redemption` | 不清楚费率、手续费、赎回规则、锁定期、到账时间 | +10 | 流动性与成本信息不足 |

## 安全减分信号

| key | 触发条件 | 分值 | 解释 |
| --- | --- | --- | --- |
| `official_platform` | 能在学校、平台、商家官方流程内完成交易 | -15 | 存在流程约束与留痕 |
| `verified_receiver` | 收款主体已通过官方页面、合同或平台实名认证核验 | -10 | 主体验证更充分 |
| `has_order_or_contract` | 提供了可验证订单号、合同、工单或平台记录 | -10 | 交易证据更完整 |
| `official_double_check` | 已通过官方客服、辅导员、学校通知或平台客服二次确认 | -15 | 核验路径更可靠 |
| `official_licensed_platform` | 通过银行、券商、持牌基金销售或官方平台开户/查看产品 | -10 | 渠道更规范 |
| `understands_product` | 能说清产品类型、底层资产、风险等级和适合人群 | -10 | 产品认知更充分 |
| `understands_fee_and_liquidity` | 已了解费率、赎回规则、锁定期或到账时间 | -10 | 成本与流动性更清楚 |
| `spare_money_investment` | 使用闲钱、小额资金，不影响生活和学业 | -15 | 资金来源相对健康 |
| `small_position_or_diversified` | 小额试投、分散配置、不重仓不满仓 | -10 | 控制风险暴露 |

## 分数与等级

- 将总分限制在 `0-100`。
- `0-29`：低风险
- `30-59`：中风险
- `60-79`：高风险
- `80-100`：极高风险

## 证据抽取规则

- 优先引用用户原文中的完整短句。
- 没有完整短句时，再引用触发规则的关键词。
- 同一证据不要重复记分或重复展示。
- 理财场景里，如果没有明显诈骗话术，也允许把“我不知道手续费”“我不清楚多久能赎回”这类信息缺口作为风险证据展示。
- 理财场景里，要区分“诈骗风险”和“决策风险”。即使不是诈骗，只要存在借钱投资、短期用钱错配、不了解产品，也应明确提示个人金融风险。

## 信息不足时的追问优先级

1. 收款主体是谁，是否和声称身份一致
2. 是否必须跳出官方平台或私下转账
3. 是否要求先交钱、验证码、密码、身份证照片、远程协助
4. 如果是理财产品：是否知道产品是什么、投什么、费率多少、多久能赎回
5. 资金是否来自闲钱，是否涉及借钱、花呗、借呗、校园分期、房租、学费或生活费重压

## 大学生投资理财补充说明

- `基金 / ETF / 指数基金`：重点关注是否知道跟踪什么指数、费率多少、是否能接受波动。
- `黄金 / 黄金主题基金`：重点关注是否把“最近涨得快”误认为“肯定继续涨”。
- `银行理财 / 锁定期产品`：重点关注是否知道锁定期、提前赎回限制、到账时间，以及是否动用了短期要用的钱。
- `个股 / 群老师带单`：重点关注是否通过官方券商 App 独立核验，是否存在开户链接、非官方链接和短期收益承诺。
